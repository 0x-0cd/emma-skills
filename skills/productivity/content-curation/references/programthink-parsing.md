## 解析过程

### 结构特征

```
= N 主标题 =         → 一级章节 (eg. = 1 政治 =)
== N.M 子标题 ==     → 二级章节 (eg. == 1.1 政治理论 ==)
=== N.M.L 细类 ===   → 三级章节 (eg. === 1.1.1 民主与宪政 ===)
```

书籍条目在 MediaWiki 表格中：

```
{|
! 中文书名 !! 英文书名 !! 作者 !! 文件类型 !! 上传日期 !! 备注
|-
| 《书名》 || English || (国) 作者 || PDF/EPUB/MOBI || 日期 || [简介]
|}
```

## 修复案例

### 分类串位 Bug

**症状：** 苏联政治人物书被塞到"中国 → 政治人物"下。

**根因：** `build_file()` 的 heading 匹配函数只比较子 heading 文本：

```python
if h_text == key_text or h_text.startswith(key_text) or key_text.startswith(h_text):
```

`#### 政治人物` 同时出现在 `### 中国` 和 `### 苏联` 下，脚本只看文本不看父级上下文。

**修复：** 删除空的 `### 中国` 骨架（所有中国政治内容已跳过），让苏联的 `#### 政治人物` 成为唯一匹配。

**教训：** heading 匹配必须带上完整的 heading 路径栈，不能只看叶子节点文本。
