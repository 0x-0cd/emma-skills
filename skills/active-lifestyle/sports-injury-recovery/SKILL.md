# Sports Injury Recovery

## When to Use This Skill

- User reports pain or discomfort from sports / exercise / running / basketball
- User asks about injury causes, recovery options, or rehab exercises
- User needs a phased return-to-sport timeline
- User wants a self-test to figure out what's wrong

Do **not** use for acute trauma (bleeding, visible deformity, inability to bear weight, suspected fracture) — direct to emergency care immediately.

## Workflow

### 1. Gather Symptom Details

Ask in order — each narrows the field:

| Question | Why it matters |
|---|---|
| **Where exactly?** Get user to point / describe landmarks | Distinguishes central vs unilateral, high vs low |
| **What makes it worse?** (run/jump/sit/walk/squat) | Each loads different structures |
| **What makes it better?** (rest/ice/specific position) | Helps differentiate inflammation vs mechanics |
| **Single-leg vs bilateral?** Pain when loading one side vs both | SI joint and hip issues are typically unilateral |
| **Acute event or gradual onset?** | Acute fall → rule out fracture; gradual → overuse pattern |
| **Any radiating pain / numbness / tingling?** | If yes → nerve involvement → refer to doctor |

### 2. Rule Out Red Flags

Refer to a medical professional if any of these are present:

- Numbness, tingling, or weakness in extremities (especially radiating below the knee)
- Loss of bladder or bowel control
- Fever, unexplained weight loss, or night sweats
- Pain lasting >2–4 weeks with no improvement from appropriate self-care
- Acute trauma with inability to bear weight or visible deformity
- Bilateral symptoms with systemic signs (possible inflammatory condition)

> Always include a disclaimer: "I'm an AI, not a doctor. This is research-informed guidance, not a medical diagnosis."

### 3. Apply Self-Assessment Tests

Build a shortlist by mapping symptoms to likely structures, then suggest a simple test the user can do at home.

| Test | What it screens | How to interpret |
|---|---|---|
| **Wall test** — stand against wall, check lumbar curve | Pelvic anterior tilt | Fist-sized gap = positive; palm-sized = normal |
| **Palpation** — feel for tender spots | Differentiate coccyx vs ischial tuberosity vs SI joint | Centered / sitting pain → coccyx; under glute med → SI joint; lower / hamstring attachment → proximal hamstring |
| **Single-leg stance** (30s, watch pelvis) | Glute medius weakness / SI stability | Pelvis drops on stance side → weak hip abductor |
| **Figure-4 test** (Faber) | Hip / SI joint / piriformis | Groin pain → hip; SI area pain → SI joint; glute stretch → piriformis |
| **Dynamic loading** — what pain level at rest / walk / run / jump? | Severity classification | See Activity Modification table below |

### 4. Classify Pain Level

| Level | Walking | Running / Jumping | Rehab approach |
|---|---|---|---|
| **Mild** | 0–1/10 | 3–5/10 | Phase 1 rehab okay; modify high-impact |
| **Moderate** | 1–3/10 | 5–7/10 | Drop high-impact; walking as tolerated |
| **Significant** | 3+/10 | 7+/10 | Stop high-impact; reduce walking volume |
| **Severe** | Limping / antalgic gait | Cannot do | Rest; consider medical consultation |

### 5. Prescribe Phased Recovery

#### Phase 1 — Pain Relief & Basic Activation (Days)
- **Goal**: Reduce irritation, re-establish pain-free movement
- **Exercises**: Gentle mobility (pelvic tilts, knee-to-chest stretches), isometric activation (glute bridges, clamshells)
- **Rule**: Pain ≤ 2/10 during and after. If sharp pain → regress or skip.
- **Avoid**: Running, jumping, heavy single-leg loading, deep loaded squats, ballistic stretching

#### Phase 2 — Strength & Stability (Weeks)
- **Goal**: Build endurance in the stabilizers that protect the joint
- **Exercises**: Single-leg bridges, bird-dog, side planks (from knees), lateral band walks
- **Rule**: Progress based on symptom response, not a fixed calendar

#### Phase 3 — Return to Sport (Ongoing)
- **Goal**: Sport-specific loading without pain
- **Progress**: Walk pain-free → jog straight-line → sport drills (no contact) → controlled scrimmage → full play
- **Rule**: Each step should be pain-free for 2–3 sessions before advancing

### 6. Recovery Timeline Expectations

- Phase 1 often resolves acute pain within **3–7 days**
- Phase 2 typically takes **2–4 weeks** of consistent work
- Full return to sport: **2–6 weeks** depending on severity and adherence
- If no progress after 2 weeks of appropriate self-care → refer to a physical therapist

## Common Regional Pain Patterns

| Region | Common Culprits | Key Distinguishers |
|---|---|---|
| **Lower back (central)** | Lumbar strain, discogenic | Bending forward worsens; may radiate |
| **Tailbone area (central)** | Coccydynia / coccyx contusion | Sitting pain; direct pressure hurts |
| **Above glute max (unilateral)** | SI joint dysfunction | Single-leg loading triggers it; unilateral |
| **Below glute / upper hamstring** | Proximal hamstring tendinopathy | Hamstring-dominant movements (running, kicking); palpate ischial tuberosity |
| **Hip / groin** | Femoroacetabular impingement, labral tear | Deep hip rotation; "C-sign" grip over greater trochanter |
| **Knee (anterior)** | Patellofemoral pain, patellar tendinopathy | Squatting / stairs / jumping exacerbates |

## Important Pitfalls

- **"Tailbone pain" is often misattributed** — the coccyx itself is central. Unilateral pain "above the butt" that worsens with single-leg loading is almost never coccydynia; it's SI joint or hamstring origin.
- **Pain level ≠ tissue damage** — sharp pain is a signal to stop, not to "push through." Mechanical irritation that is repeatedly triggered becomes chronic.
- **Rehab exercises should not reproduce the pain** — if an exercise hurts the same way the injury does, it's too aggressive. Regress (smaller range, less load, bilateral instead of unilateral).
- **Phases are not linear** — if you advance to Phase 2 and pain returns, drop back to Phase 1 until calm.
