# Basketball Shooting Mechanics

## Problem Pattern: Mid-Range Good, Three-Point Bad

This is the most common shooting inconsistency in recreational players. The root cause is almost always a **Two-Motion shot** that works for close range but fails at distance.

## One-Motion vs Two-Motion Shooting

| Feature | One-Motion | Two-Motion |
|---|---|---|
| **Timing** | Jump & shoot are one fluid motion, ball released during ascent | Jump to apex → pause → shoot |
| **Set Point** | Forehead / chin level | Above head / crown level |
| **Elbow Angle** | Forearm pointing down | Elbow pointing forward toward basket |
| **Power Source** | Legs → core → arm continuous chain | Legs lift body, arms generate throw separately |
| **Range** | Naturally longer (leg power transfers to ball) | Shorter (leg power used to jump, arms must compensate) |
| **When It Works** | Catch-and-shoot, stand-still threes | Pull-up jumpers, contested shots, mid-range |
| **Representative** | Curry, Klay, KD | Kobe, MJ, old Lebron |

## Why Mid-Range Works But Threes Don't

1. **Two-motion shooters** can hit mid-range because arm strength alone covers ~6m. At 7.24m (NBA three), arm strength maxes out → form breaks → accuracy tanks.
2. **Mid-range allows more arc and power compensation** — you can muscle the ball in with extra wrist snap or shoulder push. Three-point distance forces you into a full kinetic chain.
3. **Psychological** — players subconsciously "aim more" from three (overthinking), which disrupts the fluid one-motion rhythm.

## Key Fixes for Three-Point Shooting

### If the user has a two-motion shot and wants range:

1. **Lower the set point** to chin/forehead level (the #1 lever for range)
2. **Think "one motion"** — the ball should travel from set point to release without any pause at the top
3. **Same form, deeper legs** — don't change arm mechanics; use a deeper knee bend and more explosive hip drive
4. **Dip the ball** — let it drop to waist/hip on the catch to create upward momentum (rhythm dip)

### Common Mistakes to Debug

| Mistake | Symptom | Fix |
|---|---|---|
| Pushing with shoulder instead of using legs | Ball feels heavy like "lead" | Record video; if elbow flares out, drop set point |
| Leaning forward on release | Body drifts forward after shot | Keep vertical; land same spot you took off from |
| Flat arc | Ball hits front rim or back iron | Release earlier in the jump; push up, not out |
| Thumb-pushing / two-handed release | Ball has sideways spin | Verify guide hand releases first; shoot off index+middle |
| No wrist snap | Ball has no backspin or "dies" on rim | Full wrist follow-through; hold finish position |

## Terminology

- **甩鞭效应 (Whiplash Effect)** — sequential energy transfer from ground → ankle → knee → hip → core → shoulder → elbow → wrist → fingers, like cracking a whip
- **One-Motion (单动投篮)** — continuous upward force from ground to release point without interruption
- **Two-Motion (双动投篮)** — separate jump and shoot phases with a distinct set-point pause
